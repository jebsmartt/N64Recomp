## N64Recomp Pipeline
Repo: ~/repos/mariogolf_recomp/N64Recomp (fork)
Files:

- patch_elf.py — patches mariogolf64.elf for N64Recomp compatibility
- mariogolf.toml — recompiler config
- overlays.txt — empty (ADD30 is data-only)
- mariogolf64_patched.elf — gitignored, generated by patch_elf.py
- recomp_output/ — gitignored, generated C files (4,677 functions, 8 batched files)

## Rebuild pipeline:
```bash
bashcd ~/repos/mariogolf_recomp/mariogolf64 && make
cd ~/repos/mariogolf_recomp/N64Recomp && python3 patch_elf.py
cd build && ./N64Recomp ../mariogolf.toml
```

## Patches in patch_elf.py:

- entry_TEXT_START NOTYPE → FUNC (entrypoint detection)
- All ABS FUNC symbols in .main/.entry range → correct section (libultra/NuSystem)
- jr v0 at 0x800A384C → nop (unresolvable jump table in func_800A2F50)

## Stubs in mariogolf.toml:
29 functions — mostly callers of ADD30 overlay absolute symbols and functions containing unhandled instructions (tge, cache).
